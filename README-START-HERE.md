```bash
git add .

```

EDS auto-publishes.

## Key Concepts

### EDS = Content + Structure + Presentation

- **Content:** Markdown (from Document Authoring or .md files)
- **Structure:** HTML (auto-generated by EDS)
- **Presentation:** Blocks (CSS + JS folders)

### Blocks = Folders

Each block is:
```
blocks/block-name/
├── block-name.css  ← Styling
└── block-name.js   ← Behavior
```

### Markdown Tables = Blocks

```markdown
| Block Name |
|------------|
| Content here |
```

EDS converts this to:
```html
<div class="block-name block">
  <div>
    <div>Content here</div>
  </div>
</div>
```

Then applies CSS/JS from the block folder.
